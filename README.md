## 웹페이지 레이아웃 및 메인페이지 작성

### 개요

주제 : 맛집 정보 제공 사이트

용도 : 인기 맛집 목록 제공, 주변 맛집 목록 제공, 카테고리별 맛집 분류

### 추가 설명

기존 마켓컬리 회원가입 폼 구성과제에서 제작한 회원가입 폼에서 Primary 컬러만 변경하여 사이트의 톤앤매너를 맞추었으며 input 필드나 버튼 디자인은 로그인 페이지에도 재활용 하였습니다.

각 페이지는 Header를 기본적으로 포함하고 있으며 공용으로 사용되는 컴포넌트의 CSS 디자인은 main.css에 정의 되어 있습니다.

메인 페이지는 광고형 배너, 최근 인기 맛집 리스트, 카테고리별 맛집 리스트, 기능 바로가기, Footer 순으로 제작되어있으며
소개 페이지는 사이트의 주요 기능이라 생각되는 (지도를 구현하지는 못했습니다.) 맛집 지도를 Hero 섹션으로 설정하였고 아래에는 가상의 소개를 작성하였습니다.

사이트 전반적으로 수업에서 배운 translate나 transition을 사용하여 애니메이션을 구성하였습니다.

[참고] 음식점 이름 및 카테고리 리스트는 생성형 AI를 통해 생성하였습니다.
